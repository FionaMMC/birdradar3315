# BirdRadar
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Explore migratory birds through a geographic atlas and collectible bird stamps. Upgrade the existing course project with verifiable real data, a better interactive map, and tactile collectible artwork.

## Capabilities and Constraints
Existing Next.js / React / Leaflet application, species information pages, a Lights Out challenge, and local premium-stamp storage. The old map contains simulated points and must be replaced on the main exploration surface. Observation records do not establish individual flight routes. Historical telemetry must never be labelled live. Preserve existing species and challenge links.

## Brand Commitments
User further specifies preserving the original modern minimal art style: large background video, soft masks, oversized sans-serif type, and few hard borders. User explicitly requests Apple Weather-like layered heatmaps, translucent milky multicoloured material inspired by IMG_0020.JPG, overlapping species colours and route-density cores, and Balatro-inspired card and foil effects for postage stamps.

## Open Decisions
User confirmed global geography: start wherever verifiable real data is available. User explicitly chose complete visual mockups before frontend implementation. Existing product originated in Sydney. No deployment or external publication requested. Audience inferred from existing app: curious bird enthusiasts and participants in bird-friendly nights.
